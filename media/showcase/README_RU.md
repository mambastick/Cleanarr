# Демонстрация production-версии CleanArr

[English](README.md) · [Русский](README_RU.md)

Основные README используют эти скриншоты и **33-секундную** запись работающего
экземпляра **CleanArr v2.0.3**, сделанную **5 сентября 2026 года**.

Проверено, что развёрнут опубликованный образ `2.0.3` с digest
`sha256:0e174f17d163ba46edbe82b5875a07a94b0df330c30e0fb2ee3bec7e45ae8864`.
Интерфейс и данные отрисованы работающим приложением без подмены ответов API и
изменений исходного кода страницы. Кадры показывают конкретную установку и не
являются подтверждением совместимости или соответствия требованиям доступности.

## Смотреть

[Открыть или скачать полное видео MP4](cleanarr-demo.mp4) ·
[Русские субтитры](cleanarr-demo.ru.vtt) ·
[Английские субтитры](cleanarr-demo.en.vtt)

| Время | Что происходит |
| --- | --- |
| 00:00–00:04 | Обзор свободного места и состояния подключённых сервисов. |
| 00:04–00:10 | Открытие медиатеки с сортировкой по размеру. |
| 00:10–00:17 | Поиск фильма. |
| 00:17–00:27 | Открытие плана удаления и просмотр затрагиваемых сервисов. |
| 00:27–00:33 | Отмена подтверждения и возврат в медиатеку. |

**Для записи не подтверждалось и не запускалось удаление.** На установке уже
был включён режим реального удаления; эта настройка не менялась. Новые установки
CleanArr по умолчанию используют пробный режим. Планы и состояние сервисов
отражают только момент съёмки и не разрешают последующие операции.

## Файлы

- `library-dark.jpg` и `library-light.jpg`: медиатека для главного кадра README,
  который выбирается с учётом темы.
- `dashboard-dark.jpg` и `dashboard-light.jpg`: обзор хранилища и сервисов.
- `preflight-dark.jpg`: предварительный план удаления с закрытыми техническими
  подробностями, без выполнения изменений.
- `cleanarr-demo.mp4`: реальные кадры браузера, снятые примерно с частотой
  8 кадров/с и сохранённые как видео H.264, 1920 × 1080, 24 кадра/с. Добавлены
  поясняющие заголовки и короткое появление/затухание; паузы между фрагментами
  записи вырезаны. Звука нет.
- `demo-preview.gif`: короткий фрагмент, который проигрывается в README один раз.
- `demo-poster.jpg`: кадр из видео, также используемый при уменьшении анимации.
- `cleanarr-demo.en.vtt` и `cleanarr-demo.ru.vtt`: синхронизированные субтитры.

Скриншоты галереи сохранены в исходном JPEG-формате, возвращённом браузером.
Навигация свёрнута, чтобы исключить имя аккаунта; инициалы аватара и общие
счётчики остаются видимыми. Технические подробности
сервисов, учётные данные, приватные URL, пути файлов, меню аккаунта, история
просмотров и отдельные записи журнала действий не включены. Названия и постеры намеренно показаны
как часть медиатеки: интерфейс использует английский язык, а настроенные
метаданные — русский.

Встроенный плеер GitHub использует [опубликованное вложение](https://github.com/user-attachments/assets/6b831064-6d5e-4d4b-8154-d315432779b8)
из [Issue #36](https://github.com/mambastick/Cleanarr/issues/36). MP4 в
репозитории служит постоянной резервной ссылкой на полную запись, а
раскрываемое анимированное превью доступно, если плеер не загружается.
Оба основных README используют один набор файлов.
