## Русский

### Изменения

- Добавлены клиенты Transmission, Deluge и rTorrent наряду с расширенной поддержкой qBittorrent.
- Поддержаны legacy и JSON-RPC 2.0 поколения Transmission, Deluge Web JSON-RPC и rTorrent XML-RPC.
- Добавлена одновременная маршрутизация нескольких Radarr, Sonarr и torrent-клиентов с сохранением владельца объекта даже при совпадающих Arr ID.
- Добавлены индивидуальные политики удаления раздач: удалить сразу, оставить или отложить до достижения заданного ratio и времени сидирования.
- Добавлено сопоставление BitTorrent v1/v2 hybrid identifiers для qBittorrent.
- Добавлен полный UI для просмотра, добавления, изменения и проверки нескольких профилей torrent-клиентов.
- Добавлены protocol contract tests и проверки коллизий ID, partial failure и безопасного dry-run; backend suite расширен до 73 тестов.

### Ограничения этапа

- Автоматическое durable retry для отложенного удаления входит в v0.4.0.
- Сертификация на матрице реальных версий torrent-клиентов входит в v0.9.0.

## English

### Changes

- Added Transmission, Deluge, and rTorrent clients alongside expanded qBittorrent support.
- Covered legacy and JSON-RPC 2.0 Transmission generations, Deluge Web JSON-RPC, and rTorrent XML-RPC.
- Added simultaneous routing across multiple Radarr, Sonarr, and torrent-client instances while preserving ownership even when Arr IDs collide.
- Added per-client removal policies: remove immediately, keep, or defer until configured seeding ratio and time thresholds are met.
- Added BitTorrent v1/v2 hybrid identifier mapping for qBittorrent.
- Added a complete UI for listing, adding, editing, and testing multiple torrent-client profiles.
- Added protocol contract tests plus ID-collision, partial-failure, and safe dry-run coverage; the backend suite now contains 73 tests.

### Milestone limits

- Automatic durable retry for deferred removal remains scheduled for v0.4.0.
- Certification against a matrix of real torrent-client versions remains scheduled for v0.9.0.
