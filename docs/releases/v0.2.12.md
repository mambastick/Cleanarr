## English

### Changes

- Restored a green backend baseline: 51 tests, Ruff format/lint, and strict mypy.
- Fixed SQLite isolation in API tests so they no longer use the production-default `/config` path.
- Synchronized the Sonarr fake with the current season-unmonitoring contract.
- Fixed React Hooks and ESLint failures in background deletion jobs and the stepper UI.
- Added mandatory Quality gates for the backend, frontend, container, and native Linux packages.
- The release workflow is now blocked until all required quality gates complete successfully.
- Added real smoke tests for the built container and installed DEB/RPM packages on Ubuntu 24.04 and Rocky Linux 9.
