## Русский

### Изменения

- Зафиксирован стабильный safety-first контракт CleanArr 1.0 для цепочки
  Jellyfin → Radarr/Sonarr → Seerr → qBittorrent, Transmission, Deluge и
  rTorrent XML-RPC. Неоднозначное владение, shared/pack/cross-seed данные и
  неполные доказательства всегда завершаются структурированным пропуском.
- Все Tier 1 torrent-клиенты поддерживают dry-run, удаление только записи и
  удаление вместе с данными, идемпотентное отсутствие, per-client seeding policy
  и одновременную multi-instance маршрутизацию.
- Полные movie/series/season/episode flows используют подтверждаемый preflight,
  безопасную семантику Seerr, персистентные manual jobs, partial retry,
  webhook-idempotency и единый destructive-operation lock.
- Runtime config и SQLite используют версионированные миграции. Обязательный
  release gate проверяет upgrade и восстановление byte-identical backup для
  v0.2.11 и последнего стабильного 0.x.
- OIDC проверяет metadata/JWKS, signature, issuer, audience, expiry, nonce,
  state и PKCE; доступ требует явной policy users/groups/claims. Cookie sessions
  защищены CSRF/Origin policy и login throttling.
- Опубликованы точная compatibility matrix, policy compatibility/deprecation
  1.x, safety model и двуязычные руководства по эксплуатации и диагностике.
- Checksums, SPDX SBOM, multi-arch GHCR image, DEB/RPM для amd64/arm64 и
  подписанные GitHub attestations выпускаются из одного commit после всех
  обязательных зелёных checks.

### Обновление

Перед обновлением создайте и выгрузите проверенный SQLite backup по инструкции
для [Docker](../../README_RU.md#быстрый-запуск) или
[нативного пакета](../LINUX_PACKAGES_RU.md#резервное-копирование). Сохраните
предыдущий image/package, запустите 1.0 с `DRY_RUN=true`, проверьте health,
версии dependencies и representative previews, и только затем включайте
рабочую policy удаления.

Версии сервисов за пределами опубликованной
[матрицы](../COMPATIBILITY_RU.md) не считаются сертифицированными. Plex, Emby,
дополнительные Arr/Usenet-клиенты, PostgreSQL/HA и дополнительные языки UI не
входят в контракт 1.0.

## English

### Changes

- Established the stable CleanArr 1.0 safety-first contract for Jellyfin →
  Radarr/Sonarr → Seerr → qBittorrent, Transmission, Deluge, and rTorrent
  XML-RPC. Ambiguous ownership, shared/pack/cross-seed data, and incomplete
  evidence always produce a structured skip.
- Every Tier 1 torrent client supports dry-run, entry-only and with-data
  removal, idempotent absence, per-client seeding policy, and simultaneous
  multi-instance routing.
- Complete movie/series/season/episode flows use a confirmable preflight, safe
  Seerr semantics, persistent manual jobs, partial retry, webhook idempotency,
  and a single destructive-operation lock.
- Runtime configuration and SQLite use versioned migrations. The required
  release gate proves upgrade and byte-identical backup restoration for v0.2.11
  and the latest stable 0.x.
- OIDC validates metadata/JWKS, signature, issuer, audience, expiry, nonce,
  state, and PKCE; an explicit users/groups/claims policy is mandatory. Cookie
  sessions have CSRF/Origin protection and login throttling.
- Published the exact compatibility matrix, 1.x compatibility/deprecation
  policy, safety model, and bilingual operations and troubleshooting guides.
- Checksums, SPDX SBOMs, a multi-architecture GHCR image, amd64/arm64 DEB/RPM,
  and signed GitHub attestations are produced from one commit after every
  required check is green.

### Upgrade

Before upgrading, create and export a verified SQLite backup using the
[Docker](../../README.md#quick-start) or
[native-package](../LINUX_PACKAGES.md#backup) procedure. Preserve the previous
image/package, start 1.0 with `DRY_RUN=true`, verify health, dependency versions,
and representative previews, and only then enable the intended deletion policy.

Service versions outside the published [matrix](../COMPATIBILITY.md) are not
certified. Plex, Emby, additional Arr/Usenet clients, PostgreSQL/HA, and
additional UI languages are outside the 1.0 contract.
