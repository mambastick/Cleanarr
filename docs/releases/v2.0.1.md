## Русский

### Изменения

- Исправлена production-компоновка интерфейса: кнопка фоновых задач больше не
  перекрывает основной контент, карточки библиотеки снова показывают обложки, а
  заголовок инспектора не заходит на постер.
- Инспектор сериала теперь показывает разбивку по сезонам, а сведения об
  ownership, неполных источниках и фоновых операциях представлены понятным
  локализованным текстом вместо внутренних технических кодов.
- Экран подключённых сервисов упрощён до единого списка, а индикатор настройки
  корректно показывает завершённые обязательные интеграции.
- Добавлено fail-closed удаление одиночного фильма, который существует только в
  Jellyfin. Перед действием CleanArr повторно проверяет отсутствие фильма в
  Radarr; Arr, Seerr и torrent-клиенты при таком удалении не изменяются. Сериалы
  и пакетные операции этим путём не удаляются.

### Обновление

Обновление с v2.0.0 не изменяет schema SQLite или runtime configuration. Перед
заменой image всё равно создайте и выгрузите проверенный SQLite backup по
[Docker-инструкции](https://github.com/mambastick/Cleanarr/blob/v2.0.1/README_RU.md#быстрый-запуск)
или
[инструкции для нативного пакета](https://github.com/mambastick/Cleanarr/blob/v2.0.1/docs/LINUX_PACKAGES_RU.md#резервное-копирование).
Сохраните предыдущий image `2.0.0` и `cleanarr.config-v3.backup.db` для
rollback. Оставьте `DRY_RUN=true`, пока representative previews и ownership
evidence не будут проверены заново.

## English

### Changes

- Fixed production layout issues: the background-jobs control no longer covers
  primary content, library cards render artwork again, and inspector headings
  no longer overlap posters.
- The series inspector now includes a per-season breakdown, while ownership,
  partial-source, and background-operation details use clear localized copy
  instead of internal technical codes.
- The connected-services screen is now a single flat list, and setup progress
  correctly recognizes completed required integrations.
- Added fail-closed deletion for a single movie that exists only in Jellyfin.
  CleanArr revalidates the movie's absence from Radarr immediately before the
  action; Arr, Seerr, and torrent clients are not mutated. Series and batch
  operations cannot use this path.

### Upgrade

Upgrading from v2.0.0 does not change the SQLite or runtime-configuration
schema. Before replacing the image, still create and export a verified SQLite
backup using the
[Docker procedure](https://github.com/mambastick/Cleanarr/blob/v2.0.1/README.md#quick-start)
or
[native-package procedure](https://github.com/mambastick/Cleanarr/blob/v2.0.1/docs/LINUX_PACKAGES.md#backup).
Retain the previous `2.0.0` image and `cleanarr.config-v3.backup.db` for
rollback. Keep `DRY_RUN=true` until representative previews and ownership
evidence have been revalidated.
