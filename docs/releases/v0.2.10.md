## Русский

### Исправления

- API теперь корректно сообщает доступность SSO независимо от локальной парольной авторизации.
- Состояние способов входа обновляется после сохранения настроек и выхода из сессии.
- В режиме `SSO only` форма больше не показывает отключённые поля логина и пароля.
- Добавлены regression-тесты режимов `password_only`, `both` и `sso_only`.

### Артефакты

- Контейнер: `ghcr.io/mambastick/cleanarr:0.2.10` для `linux/amd64` и `linux/arm64`.
- Нативные DEB- и RPM-пакеты для `amd64` и `arm64`.

## English

### Fixes

- The API now reports SSO availability independently from local password authentication.
- Available sign-in methods are refreshed after settings are saved and after logout.
- SSO-only mode no longer displays disabled username and password fields.
- Regression coverage was added for `password_only`, `both`, and `sso_only` modes.

### Artifacts

- Container: `ghcr.io/mambastick/cleanarr:0.2.10` for `linux/amd64` and `linux/arm64`.
- Native DEB and RPM packages for `amd64` and `arm64`.
