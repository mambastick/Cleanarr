## Русский

### Изменения

- Добавлена упорядоченная цепочка версий runtime config и SQLite с проверяемым backup/restore и отклонением неизвестных будущих схем без перезаписи.
- OIDC login теперь строго проверяет discovery metadata, JWKS-подпись и алгоритм, issuer, audience, expiry, issued-at, nonce и `azp`; PKCE S256 и одноразовый browser-bound state обязательны.
- Для SSO требуется явная allow policy по пользователю, группе или claim; добавлены throttling локального входа, CSRF/same-origin защита, безопасные session cookies и security headers.
- Добавлены credential-free export и fail-safe import конфигурации: импортированные профили отключаются, credentials не переносятся, локальная auth-конфигурация сохраняется, а dry-run включается принудительно.
- Добавлены аутентифицированные privacy-safe Prometheus-метрики, редактированный support bundle и correlation ID для результатов обработки и структурированных логов.
- Централизованный redaction закрывает credentials в логах, activity actions, вложенных diagnostic details, external-service errors и ошибках фоновых заданий.
- Required CI теперь включает Python dependency audit, Trivy source/config/secret и container scans. Release assets получают SPDX JSON SBOM, SHA-256 checksums и подписанные GitHub attestations; GHCR image получает digest-bound build и SBOM attestations.
- Frontend dependencies обновлены без известных High-уязвимостей; backend suite расширен до 117 тестов.

### Ограничения этапа

- Сертификация на матрице реальных поддерживаемых версий Jellyfin, Radarr, Sonarr, Seerr и Tier 1 torrent clients остаётся обязательным gate v0.9.0.
- PostgreSQL, HA и несколько одновременно работающих экземпляров CleanArr не входят в границы 1.0.

## English

### Changes

- Added ordered runtime-config and SQLite schema chains with verified backup/restore and fail-closed rejection of unknown future schemas.
- OIDC login now strictly validates discovery metadata, the JWKS signature and algorithm, issuer, audience, expiry, issued-at, nonce, and `azp`; PKCE S256 and one-time browser-bound state are mandatory.
- SSO requires an explicit user, group, or claim allow policy; local-login throttling, CSRF/same-origin protection, secure session cookies, and security headers are enforced.
- Added credential-free configuration export and fail-safe import: imported profiles are disabled, credentials are not transferred, local authentication configuration is preserved, and dry-run is forced.
- Added authenticated privacy-safe Prometheus metrics, a redacted support bundle, and correlation IDs shared by processing results and structured logs.
- Central redaction covers credentials in logs, activity actions, nested diagnostic details, external-service errors, and background-job failures.
- Required CI now includes Python dependency auditing plus Trivy source/configuration/secret and container scans. Release assets receive SPDX JSON SBOMs, SHA-256 checksums, and signed GitHub attestations; the GHCR image receives digest-bound build and SBOM attestations.
- Updated frontend dependencies with no known High vulnerabilities and expanded the backend suite to 117 tests.

### Milestone limits

- Certification against real supported versions of Jellyfin, Radarr, Sonarr, Seerr, and every Tier 1 torrent client remains a required v0.9.0 gate.
- PostgreSQL, HA, and multiple simultaneously active CleanArr instances remain outside the 1.0 product boundary.
