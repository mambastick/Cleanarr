## Русский

### Изменения

- Восстановлено удаление отдельного сезона: Библиотека → Сериалы → карточка сериала → «Удалить сезон». План относится к выбранному сезону; остальные сезоны и запись сериала сохраняются.
- Прямое удаление из Jellyfin использует только однозначно сопоставленный сезон. ID родительского сериала, другого сезона и неоднозначные связи отклоняются; при отсутствии связи прямое действие Jellyfin не добавляется.
- Предпросмотр одиночного удаления показывает названия торрентов, пути, конкретные записи Seerr, последствия для файлов и ссылки для проверки объектов. Точный путь данных отличается от папки загрузки; неизвестные данные явно обозначены.
- Убрана кнопка «Недавние». История остаётся в «Активности», а панель фоновых задач доступна во время выполнения и сохраняет результат уже открытой задачи.
- Исправлены наложение окна подтверждения на мобильном экране, возврат фокуса и контраст кнопок. Расширены проверки EN/RU, тем, клавиатуры и повторной отправки.

### Обновление и откат

Схемы SQLite 6 и конфигурации 4 не меняются. Перед обновлением сохраните и проверьте backup SQLite. Закройте старые предпросмотры и получите новые планы: добавленные сведения входят в hash подтверждения. При необходимости остановите CleanArr, закрепите образ 2.0.3 и восстановите проверенный backup, сохранив состояние неудачного обновления отдельно. Процедуры описаны в [руководстве эксплуатации](https://github.com/mambastick/Cleanarr/blob/v2.0.4/docs/OPERATIONS_RU.md).

Релизный gate включает обновление заполненной установки 2.0.3 и откат из backup в дополнение к существующим проверкам совместимости.

## English

### Changes

- Restored individual season deletion: Library → Series → series details → Delete season. The plan targets the selected season and retains other seasons and the series record.
- Direct Jellyfin cleanup uses only an unambiguous matched season. Parent-series IDs, other seasons, and ambiguous bindings are rejected; a missing binding omits the direct Jellyfin action.
- The single-item preview identifies torrent names, paths, individual Seerr records, file effects, and inspection links. Exact content paths are distinguished from download directories, and missing metadata is explicit.
- Removed the Recent control. History remains in Activity; the background-work panel is available during active work and retains a followed task's result.
- Fixed mobile confirmation stacking, focus restoration, and button contrast. Expanded EN/RU, theme, keyboard, and submission-retry regression coverage.

### Upgrade and rollback

SQLite schema 6 and configuration schema 4 are unchanged. Create and verify a SQLite backup before upgrading. Close old previews and generate fresh plans: the added metadata participates in the confirmation hash. To roll back, stop CleanArr, pin image 2.0.3, and restore the verified backup while preserving the failed state separately. See the [operations guide](https://github.com/mambastick/Cleanarr/blob/v2.0.4/docs/OPERATIONS.md).

The release gate includes a seeded 2.0.3 upgrade and backup rollback in addition to the existing compatibility checks.
