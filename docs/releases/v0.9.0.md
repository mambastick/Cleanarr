## Русский

### Изменения

- Опубликована точная compatibility matrix для qBittorrent 5.2.3,
  Transmission 4.0.6 и 4.1.3, Deluge 2.2.0, rTorrent 0.16.17, Radarr
  6.3.0.10514, Sonarr 4.0.19.2979, Seerr 3.4.1 и Jellyfin 10.11.11.
- Новый обязательный release gate запускает все digest-pinned реальные сервисы,
  проверяет версии и fail-closed authentication и выполняет оба режима удаления
  реальной тестовой раздачи во всех Tier 1 torrent-клиентах.
- Исправлено удаление Deluge при несовпадении регистра фактического info hash и
  нормализованного identifier CleanArr. Исправлен вызов `execute.throw` для
  remove-with-data в реальном XML-RPC rTorrent.
- Health check Jellyfin теперь использует аутентифицированный `/System/Info` и
  действительно отклоняет неверный API token.
- Автоматизированная репетиция обновляет реальные v0.2.11 и v0.5.0 до candidate,
  проверяет миграцию config/database и activity history, а затем восстанавливает
  byte-identical проверенный backup и запускает исходный релиз.
- Опубликована двуязычная policy совместимости/deprecation серии 1.x. Feature
  scope 1.0 заморожен; release не публикуется при красном compatibility gate.

### Обновление

Перед обновлением создайте и выгрузите проверенный SQLite backup по инструкции
для [Docker](../../README_RU.md#быстрый-запуск) или
[нативного пакета](../LINUX_PACKAGES_RU.md#резервное-копирование). После запуска
оставьте `DRY_RUN=true`, проверьте health и preview на своей конфигурации и
только затем возвращайте рабочую policy удаления.

## English

### Changes

- Published an exact compatibility matrix for qBittorrent 5.2.3, Transmission
  4.0.6 and 4.1.3, Deluge 2.2.0, rTorrent 0.16.17, Radarr 6.3.0.10514, Sonarr
  4.0.19.2979, Seerr 3.4.1, and Jellyfin 10.11.11.
- A new required release gate starts every digest-pinned real service, verifies
  versions and fail-closed authentication, and exercises both removal modes on
  a real fixture torrent in every Tier 1 client.
- Fixed Deluge removal when the actual info-hash case differs from CleanArr's
  normalized identifier. Fixed the `execute.throw` call used for rTorrent
  XML-RPC remove-with-data.
- The Jellyfin health check now calls authenticated `/System/Info` and actually
  rejects an invalid API token.
- An automated rehearsal upgrades real v0.2.11 and v0.5.0 installations to the
  candidate, verifies config/database migration and activity history, then
  restores a byte-identical verified backup and starts the source release.
- Published the bilingual 1.x compatibility/deprecation policy. The 1.0 feature
  scope is frozen and a red compatibility gate blocks release publication.

### Upgrade

Before upgrading, create and export a verified SQLite backup using the
[Docker](../../README.md#quick-start) or
[native-package](../LINUX_PACKAGES.md#backup) procedure. Keep `DRY_RUN=true`
after startup, verify health and a preview against your configuration, and only
then restore the intended deletion policy.
